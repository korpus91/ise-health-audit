# Security Policy

## Maintainer

Security maintainer: Arkadiy Ayrapetov (GitHub: korpus91)

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub's private vulnerability reporting on this repository, or by email to Arkadiy@aglitch.com. Do not open a public issue for security problems.

Expect an acknowledgement within 7 days. Confirmed issues are fixed and disclosed in a release note crediting the reporter unless they prefer otherwise.

## Scope

ise-health-audit is designed to be read-only. Any behavior that changes device or system state, leaks credentials or configuration outside the local output folders, or can be abused through crafted input is in scope.
